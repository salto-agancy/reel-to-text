# V3. Кнопка «В текст» на iPhone

## Что это

«В текст» — не встроенная кнопка iPhone, а наша команда в приложении «Команды» (Shortcuts). Отдельное приложение писать не нужно.

Сценарий:

```
Instagram → Reel → Поделиться → «В текст»
      ↓
через несколько секунд: текст в буфере обмена + уведомление «Готово»
```

Дальше открываете ChatGPT, Claude или Заметки и вставляете.

## Как появится в меню «Поделиться»

1. В «Командах» создаётся команда «В текст».
2. В её настройках включается «Показывать в меню „Поделиться“», тип входа: URL и текст.
3. В Instagram: «Поделиться» → внизу «Редактировать действия» → добавить «В текст» и поднять повыше.

## Что делает команда

1. Получает вход из меню «Поделиться».
2. Если пришёл не чистый URL, а текст со ссылкой, достаёт ссылку действием «Получить URL из ввода». Сервер тоже умеет искать ссылку в тексте, так что можно отправлять текст целиком.
3. «Получить содержимое URL»: `POST https://<наш-домен>/v1/transcribe`, заголовок `Authorization: Bearer <личный токен>`, тело JSON `{"url": "<ссылка>"}`.
4. Из ответа берёт поле `text`.
5. «Скопировать в буфер обмена».
6. «Показать уведомление»: «Текст ролика скопирован».

При ошибке сервер отвечает `{"error": "not_found", "message": "Ролик приватный или удалён"}`, команда показывает `message`.

## Что нужно на сервере

Серверная логика уже есть, это ядро. Добавляется только тонкий HTTP-интерфейс:

- `interfaces/http/`: `POST /v1/transcribe` → `core.transcribe(url, requester="ios:<token-id>")`;
- токены на пользователя в env или в SQLite;
- публикация через Cloudflare Tunnel.

Лимиты, кэш и защита баланса — те же, что у бота.
